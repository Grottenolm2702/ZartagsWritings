\section{Code-Test mit Umlauten}

Unter Lua\LaTeX{} funktionieren die Umlaute im Code \ref{lst:java-test} komplett ohne Hacks:
\cite{beispiel2026}

\begin{lstlisting}[language={Java}, caption={Java-Code unter LuaLaTeX}, label={lst:java-test}]
// Schöne Grüße aus der Arch-Linux-Ecke!
public class Main {
    public static void main(String[] args) {
        System.out.println("Umlaute: Ä, Ö, Ü, ß funktionieren einfach so.");
    }
}
\end{lstlisting}

\begin{lstlisting}[style=terminal, caption={Konsolenausgabe im Light-Mode-Stil}, label={lst:terminal-output}]
$ javac Main.java
$ java Main
Process finished with exit code 0
\end{lstlisting}
